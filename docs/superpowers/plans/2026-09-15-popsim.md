# PopSim Implementation Plan

> **Revision 2, implemented on branch `popsim` (2026-09-15).** The code on the branch supersedes the task code below wherever they differ. What changed after checking the plan against the code and the cached town data:
> - **Households** come from every building the town query already downloads (it fetched them all, then kept 4,000 for the browser), grouped into 50 m clusters. A full-detail Overpass fetch around the leading sites is the fallback.
> - **Today's sources** are wells, boreholes, springs and drinking-water taps only. Reservoirs, water towers and treatment works are infrastructure, not places people fill containers.
> - **Placement:** each system type is anchored to what it physically needs (a roadside borehole or tanker tank, a school or clinic roof, a raw-water source, the existing well it restores). Taps are sited one at a time where they save the most walking for people not yet served. Pipes follow the streets.
> - **Ranking** uses whole-life cost (capital plus 10 years of operation, including trucked water and filter consumables) per person served, so a capital-light option with heavy running costs cannot win on capital alone.
> - **Futures** draw borehole yield across its band, simulate rainwater storage week by week with year-to-year rainfall, break systems down at long-run out-of-service shares, and grow the town with new clusters beside existing ones.
> - **Decision rule:** the cheapest per person among projects that hold in at least 70% of futures.
> - **Dropped:** satellite roof counting. General vision models miscount dense roofs; ML building-footprint datasets are the right tool if OpenStreetMap proves too thin.
>
> Modules: `lib/popsim/{engine,network,demand,baseline,placement,evaluate,scenarios,rng,stats}.ts`, `lib/providers/local-osm.ts`, `lib/cost-model/lifecycle.ts`, `lib/evidence/rates.ts`, `scripts/recache.ts`.

**Goal:** Replace "people in a radius" with a household-level model that tests every viable site and system type against every mapped household, stresses the best projects across seeded futures, and attaches the result to every analysis run.

**Architecture:** Three pure stages after the existing site ranking. Stage 2 (`evaluate`) assigns every household to its best source for each viable site × 5 system types and yields people served, walk minutes and cost per person. Stage 3 (`simulate`) replays the shortlist through weekly seeded futures with breakdowns, dry seasons and growth. `scenarios` orchestrates both and produces one `SimulationResult` that `pipeline.ts` stores as `run.simulation`. Households live in typed arrays; nothing per household is an object.

**Tech Stack:** TypeScript, Next.js 16 route handlers, `node:test` via `tsx`, `@turf/turf` only where the codebase already uses it. No new dependencies.

**Spec:** This conversation's agreed scope. Six items: households from OSM buildings; assignment for every viable site × 5 types; seeded futures with breakdowns, dry seasons, growth and capacity year; ranking with p10/median/p90 and "held in N of K futures"; type contract and fixture first; pipeline wiring, new track, re-cache the three demo towns.

## Global Constraints

- Determinism: identical inputs and seed produce byte-identical output. `Math.random()` is forbidden in `lib/popsim/`. All randomness goes through `lib/popsim/rng.ts`.
- Every planning number lives in `lib/config/coefficients.ts` with a `source` string. New ones use the existing `DEMO` label until Eric replaces them.
- No object per household. Households and per-household results are typed arrays.
- Nothing in `lib/popsim/` imports from `components/` or `app/`.
- Tests run with `npm test` (`node --import tsx --test lib/__tests__/*.test.ts`). New tests go in `lib/__tests__/popsim-*.test.ts`.
- `npm run typecheck` and `npm run lint` must pass at every commit.
- Existing cached runs in `data/runs/` lack `simulation`; the loader must default it to `null` so old snapshots still open.
- Branch: `popsim` off `main`. One commit per task.

```ts
// lib/popsim/rng.ts
/**
 * mulberry32: a small, fast, seedable 32-bit generator. Good enough for
 * scenario sampling and, unlike Math.random(), reproducible.
 */
export type Rng = {
  /** Uniform in [0, 1). */
  next(): number;
  /** Uniform integer in [low, high], both inclusive. */
  int(low: number, high: number): number;
};

export function createRng(seed: number): Rng {
  let a = seed >>> 0;
  const next = (): number => {
    a = (a + 0x6d2b79f5) >>> 0;
    let t = a;
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
  return {
    next,
    int: (low, high) => low + Math.floor(next() * (high - low + 1)),
  };
}
```

```ts
// lib/popsim/geo.ts
/**
 * Local planar geometry for the simulation. A town is at most ~24 km across,
 * so equirectangular scaling is accurate to well under a percent and avoids a
 * geodesic call per household per source per week.
 */
import { BEHAVIOUR } from "@/lib/config/coefficients";

const EARTH_RADIUS_M = 6371008.8;
const M_PER_DEG_LAT = (Math.PI * EARTH_RADIUS_M) / 180;

export type PlanarScale = { mPerDegLon: number; mPerDegLat: number };

export function planarScale(lat: number): PlanarScale {
  const cos = Math.cos((lat * Math.PI) / 180);
  return { mPerDegLon: Math.max(M_PER_DEG_LAT * cos, 1), mPerDegLat: M_PER_DEG_LAT };
}

export function distanceM(
  s: PlanarScale,
  lon1: number,
  lat1: number,
  lon2: number,
  lat2: number,
): number {
  const dx = (lon2 - lon1) * s.mPerDegLon;
  const dy = (lat2 - lat1) * s.mPerDegLat;
  return Math.sqrt(dx * dx + dy * dy);
}

const METRES_PER_MINUTE = (BEHAVIOUR.walkingSpeedKmh.value * 1000) / 60;

/** One-way walking minutes along a route detourFactor times the straight line. */
export function walkMinutesOneWay(metres: number): number {
  if (!(metres > 0)) return 0;
  return (metres * BEHAVIOUR.detourFactor.value) / METRES_PER_MINUTE;
}
```

```ts
// lib/popsim/households.ts
/**
 * Households for the simulation. One row per mapped building centroid; every
 * row carries a weight equal to the Overpass sample ratio so totals scale back
 * to the real settlement. Typed arrays throughout: the simulation touches every
 * row every week and object-per-household would dominate the run time.
 */
import type { OsmData } from "@/lib/types";
import { SERVICE, WATER } from "@/lib/config/coefficients";

export type Households = {
  count: number;
  capacity: number;
  lon: Float64Array;
  lat: Float64Array;
  people: Float64Array;
  weight: Float64Array;
  demandL: Float64Array;
  peopleTotal: number;
  sampleRatio: number;
};

export type ExtraHousehold = { lon: number; lat: number; weight: number };

const PEOPLE_PER_HOUSEHOLD =
  (SERVICE.peoplePerBuilding.low + SERVICE.peoplePerBuilding.high) / 2;
const LITRES = WATER.litersPerPersonPerDay.value;

/** Default headroom: ten years of compound growth at a generous rate stays under this. */
const DEFAULT_GROWTH_HEADROOM = 1.6;

function alloc(capacity: number, sampleRatio: number): Households {
  return {
    count: 0,
    capacity,
    lon: new Float64Array(capacity),
    lat: new Float64Array(capacity),
    people: new Float64Array(capacity),
    weight: new Float64Array(capacity),
    demandL: new Float64Array(capacity),
    peopleTotal: 0,
    sampleRatio,
  };
}

export function addHousehold(h: Households, lon: number, lat: number, weight: number): number {
  if (h.count >= h.capacity) return -1;
  if (!Number.isFinite(lon) || !Number.isFinite(lat) || !(weight > 0)) return -1;
  const i = h.count++;
  h.lon[i] = lon;
  h.lat[i] = lat;
  h.people[i] = PEOPLE_PER_HOUSEHOLD;
  h.weight[i] = weight;
  h.demandL[i] = PEOPLE_PER_HOUSEHOLD * weight * LITRES;
  h.peopleTotal += PEOPLE_PER_HOUSEHOLD * weight;
  return i;
}

export function buildHouseholds(
  osm: OsmData,
  extra: ExtraHousehold[] = [],
  growthHeadroom: number = DEFAULT_GROWTH_HEADROOM,
): Households {
  const sampleRatio = Number.isFinite(osm.buildingSampleRatio)
    ? Math.max(1, osm.buildingSampleRatio)
    : 1;
  const base = osm.buildings.length + extra.length;
  const h = alloc(Math.max(1, Math.ceil(base * Math.max(1, growthHeadroom))), sampleRatio);
  for (const b of osm.buildings) addHousehold(h, b.lon, b.lat, sampleRatio);
  for (const e of extra) addHousehold(h, e.lon, e.lat, e.weight);
  return h;
}

export function cloneHouseholds(h: Households): Households {
  return {
    ...h,
    lon: h.lon.slice(),
    lat: h.lat.slice(),
    people: h.people.slice(),
    weight: h.weight.slice(),
    demandL: h.demandL.slice(),
  };
}
```

Design notes for the implementer:
- Vertices are merged by rounding to 1e-5 degrees (about 1 m). OSM ways share nodes at junctions, so this is what connects one road to the next.
- Snapping uses a uniform grid index with 250 m cells, searching outward ring by ring up to `SNAP_RADIUS_M`. Brute force over 100k nodes per household is too slow.
- Both Dijkstra variants use a binary heap over `(dist, node)` pairs stored in two parallel arrays. No object per heap entry.
- A source's initial distance is its own snap offset, so a tap 40 m off the road starts at 40, not 0.

```ts
// lib/popsim/roads.ts
/**
 * Walking network from the OSM road lines already fetched for the town.
 * Households and water sources are snapped to the nearest road vertex and
 * distances are shortest paths over the network, so "how far is the tap" is a
 * route, not a straight line. Straight-line is only a fallback for points
 * that sit more than SNAP_RADIUS_M from any mapped road.
 */
import type { OsmLine } from "@/lib/types";
import { distanceM, type PlanarScale } from "@/lib/popsim/geo";

export type RoadGraph = {
  nodeCount: number;
  nodeLon: Float64Array;
  nodeLat: Float64Array;
  adjStart: Int32Array;
  adjTo: Int32Array;
  adjW: Float64Array;
  scale: PlanarScale;
};

export type Snap = { node: Int32Array; offsetM: Float64Array };

export const SNAP_RADIUS_M = 500;
const SNAP_CELL_M = 250;
const MERGE_DECIMALS = 1e5;

function key(lon: number, lat: number): string {
  return `${Math.round(lon * MERGE_DECIMALS)},${Math.round(lat * MERGE_DECIMALS)}`;
}

export function buildRoadGraph(roads: OsmLine[], scale: PlanarScale): RoadGraph | null {
  const ids = new Map<string, number>();
  const lons: number[] = [];
  const lats: number[] = [];
  const from: number[] = [];
  const to: number[] = [];
  const w: number[] = [];

  const nodeFor = (lon: number, lat: number): number => {
    const k = key(lon, lat);
    let id = ids.get(k);
    if (id === undefined) {
      id = lons.length;
      ids.set(k, id);
      lons.push(lon);
      lats.push(lat);
    }
    return id;
  };

  for (const road of roads) {
    let prev = -1;
    for (const c of road.coords) {
      if (!Number.isFinite(c[0]) || !Number.isFinite(c[1])) continue;
      const cur = nodeFor(c[0], c[1]);
      if (prev >= 0 && prev !== cur) {
        const d = distanceM(scale, lons[prev], lats[prev], lons[cur], lats[cur]);
        from.push(prev, cur);
        to.push(cur, prev);
        w.push(d, d);
      }
      prev = cur;
    }
  }
  const n = lons.length;
  if (n < 2) return null;

  // Counting sort edges into CSR form.
  const adjStart = new Int32Array(n + 1);
  for (const f of from) adjStart[f + 1]++;
  for (let i = 0; i < n; i++) adjStart[i + 1] += adjStart[i];
  const fill = adjStart.slice(0, n);
  const adjTo = new Int32Array(from.length);
  const adjW = new Float64Array(from.length);
  for (let e = 0; e < from.length; e++) {
    const slot = fill[from[e]]++;
    adjTo[slot] = to[e];
    adjW[slot] = w[e];
  }
  return {
    nodeCount: n,
    nodeLon: Float64Array.from(lons),
    nodeLat: Float64Array.from(lats),
    adjStart,
    adjTo,
    adjW,
    scale,
  };
}

/** Uniform grid over the nodes so snapping is O(cells searched), not O(nodes). */
function gridIndex(g: RoadGraph) {
  const cellLon = SNAP_CELL_M / g.scale.mPerDegLon;
  const cellLat = SNAP_CELL_M / g.scale.mPerDegLat;
  const cells = new Map<string, number[]>();
  for (let i = 0; i < g.nodeCount; i++) {
    const k = `${Math.floor(g.nodeLon[i] / cellLon)},${Math.floor(g.nodeLat[i] / cellLat)}`;
    const list = cells.get(k);
    if (list) list.push(i);
    else cells.set(k, [i]);
  }
  return { cellLon, cellLat, cells };
}

export function snapPoints(
  g: RoadGraph,
  lon: ArrayLike<number>,
  lat: ArrayLike<number>,
  count: number,
): Snap {
  const idx = gridIndex(g);
  const rings = Math.ceil(SNAP_RADIUS_M / SNAP_CELL_M);
  const node = new Int32Array(count).fill(-1);
  const offsetM = new Float64Array(count).fill(Infinity);

  for (let p = 0; p < count; p++) {
    const cx = Math.floor(lon[p] / idx.cellLon);
    const cy = Math.floor(lat[p] / idx.cellLat);
    let best = -1;
    let bestD = Infinity;
    for (let r = 0; r <= rings; r++) {
      for (let dx = -r; dx <= r; dx++) {
        for (let dy = -r; dy <= r; dy++) {
          if (Math.max(Math.abs(dx), Math.abs(dy)) !== r) continue;
          const list = idx.cells.get(`${cx + dx},${cy + dy}`);
          if (!list) continue;
          for (const i of list) {
            const d = distanceM(g.scale, lon[p], lat[p], g.nodeLon[i], g.nodeLat[i]);
            if (d < bestD) {
              bestD = d;
              best = i;
            }
          }
        }
      }
      // Anything in a later ring is at least r * SNAP_CELL_M away.
      if (best >= 0 && bestD <= r * SNAP_CELL_M) break;
    }
    if (best >= 0 && bestD <= SNAP_RADIUS_M) {
      node[p] = best;
      offsetM[p] = bestD;
    }
  }
  return { node, offsetM };
}

/** Minimal binary heap on parallel arrays. */
class Heap {
  private d: number[] = [];
  private n: number[] = [];
  get size() { return this.d.length; }
  push(dist: number, node: number) {
    const d = this.d, n = this.n;
    d.push(dist); n.push(node);
    let i = d.length - 1;
    while (i > 0) {
      const p = (i - 1) >> 1;
      if (d[p] <= d[i]) break;
      [d[p], d[i]] = [d[i], d[p]];
      [n[p], n[i]] = [n[i], n[p]];
      i = p;
    }
  }
  pop(): [number, number] {
    const d = this.d, n = this.n;
    const top: [number, number] = [d[0], n[0]];
    const ld = d.pop() as number, ln = n.pop() as number;
    if (d.length > 0) {
      d[0] = ld; n[0] = ln;
      let i = 0;
      for (;;) {
        const l = 2 * i + 1, r = l + 1;
        let m = i;
        if (l < d.length && d[l] < d[m]) m = l;
        if (r < d.length && d[r] < d[m]) m = r;
        if (m === i) break;
        [d[m], d[i]] = [d[i], d[m]];
        [n[m], n[i]] = [n[i], n[m]];
        i = m;
      }
    }
    return top;
  }
}

function dijkstra(
  g: RoadGraph,
  sourceNodes: number[],
  sourceOffsetsM: number[],
  cutoffM: number,
  label: Int32Array | null,
): Float64Array {
  const dist = new Float64Array(g.nodeCount).fill(Infinity);
  const heap = new Heap();
  sourceNodes.forEach((s, i) => {
    if (s < 0) return;
    const d0 = Number.isFinite(sourceOffsetsM[i]) ? sourceOffsetsM[i] : 0;
    if (d0 < dist[s]) {
      dist[s] = d0;
      if (label) label[s] = i;
      heap.push(d0, s);
    }
  });
  while (heap.size > 0) {
    const [d, u] = heap.pop();
    if (d > dist[u]) continue;
    if (d > cutoffM) break;
    for (let e = g.adjStart[u]; e < g.adjStart[u + 1]; e++) {
      const v = g.adjTo[e];
      const nd = d + g.adjW[e];
      if (nd < dist[v]) {
        dist[v] = nd;
        if (label) label[v] = label[u];
        heap.push(nd, v);
      }
    }
  }
  if (Number.isFinite(cutoffM)) {
    for (let i = 0; i < dist.length; i++) if (dist[i] > cutoffM) dist[i] = Infinity;
  }
  return dist;
}

export function boundedDistances(
  g: RoadGraph,
  sourceNodes: number[],
  sourceOffsetsM: number[],
  cutoffM: number,
): Float64Array {
  return dijkstra(g, sourceNodes, sourceOffsetsM, cutoffM, null);
}

export function labelledDistances(
  g: RoadGraph,
  sourceNodes: number[],
  sourceOffsetsM: number[],
): { dist: Float64Array; label: Int32Array } {
  const label = new Int32Array(g.nodeCount).fill(-1);
  const dist = dijkstra(g, sourceNodes, sourceOffsetsM, Infinity, label);
  return { dist, label };
}
```

```ts
// lib/popsim/sources.ts
/**
 * Water sources as the simulation sees them.
 *
 * Baseline: for each household, the nearest existing mapped water points.
 * Slot 0 is a routed distance over the road network from one labelled
 * multi-source search; slots 1-2 are the next-nearest by straight line and
 * exist only so a household has somewhere to go when its usual source is
 * broken. Taps: the proposed project's stands, each with a routed distance
 * per household from a bounded search, and two capacity limits.
 */
import type { LngLat, OsmPoint } from "@/lib/types";
import { BEHAVIOUR } from "@/lib/config/coefficients";
import { distanceM, planarScale, walkMinutesOneWay } from "@/lib/popsim/geo";
import type { Households } from "@/lib/popsim/households";
import { boundedDistances, labelledDistances, snapPoints, type RoadGraph, type Snap } from "@/lib/popsim/roads";

export const BASELINE_K = 3;
/** Walking beyond this on the road is never a basic service; treat as unreachable. */
export const ROUTE_CUTOFF_M = 3000;

export type Baseline = {
  sourceCount: number;
  sourceLon: Float64Array;
  sourceLat: Float64Array;
  idx: Int32Array;
  minutesOneWay: Float64Array;
  routedCount: number;
  fallbackCount: number;
};

export type Taps = {
  count: number;
  lon: Float64Array;
  lat: Float64Array;
  systemDailyL: number;
  perTapDailyL: number;
  minutesOneWay: Float64Array;
  routedCount: number;
  fallbackCount: number;
};

function perTapDailyLitres(): number {
  const containersPerDay =
    (BEHAVIOUR.tapWindowHours.value * 60) / BEHAVIOUR.containerFillMinutes.value;
  return containersPerDay * BEHAVIOUR.containerLitres.value;
}

/** Straight-line minutes, or Infinity when the walk is beyond the route cutoff. */
function straightMinutes(h: Households, i: number, lon: number, lat: number): number {
  const s = planarScale(h.lat[i]);
  const d = distanceM(s, h.lon[i], h.lat[i], lon, lat);
  return d <= ROUTE_CUTOFF_M ? walkMinutesOneWay(d) : Infinity;
}

export function buildBaseline(
  h: Households,
  waterPoints: OsmPoint[],
  graph: RoadGraph | null,
  hhSnap: Snap | null,
): Baseline {
  const pts = waterPoints.filter((p) => Number.isFinite(p.lon) && Number.isFinite(p.lat));
  const n = pts.length;
  const idx = new Int32Array(h.capacity * BASELINE_K).fill(-1);
  const minutesOneWay = new Float64Array(h.capacity * BASELINE_K).fill(Infinity);
  const sourceLon = Float64Array.from(pts, (p) => p.lon);
  const sourceLat = Float64Array.from(pts, (p) => p.lat);
  let routedCount = 0;
  let fallbackCount = 0;

  if (n === 0) {
    return { sourceCount: 0, sourceLon, sourceLat, idx, minutesOneWay, routedCount, fallbackCount };
  }

  // Slot 0: routed nearest source where the network allows it.
  let routed: { dist: Float64Array; label: Int32Array } | null = null;
  let srcSnap: Snap | null = null;
  if (graph && hhSnap) {
    srcSnap = snapPoints(graph, sourceLon, sourceLat, n);
    const nodes = Array.from(srcSnap.node);
    const offsets = Array.from(srcSnap.offsetM);
    routed = labelledDistances(graph, nodes, offsets);
  }

  for (let i = 0; i < h.count; i++) {
    const row = i * BASELINE_K;
    // Straight-line ranking of all sources for this household.
    const s = planarScale(h.lat[i]);
    const order: number[] = [];
    const dists: number[] = [];
    for (let j = 0; j < n; j++) {
      dists.push(distanceM(s, h.lon[i], h.lat[i], sourceLon[j], sourceLat[j]));
      order.push(j);
    }
    order.sort((a, b) => dists[a] - dists[b] || a - b);

    let slot = 0;
    const node = hhSnap ? hhSnap.node[i] : -1;
    if (routed && node >= 0 && Number.isFinite(routed.dist[node]) && routed.label[node] >= 0) {
      idx[row] = routed.label[node];
      minutesOneWay[row] = walkMinutesOneWay((hhSnap as Snap).offsetM[i] + routed.dist[node]);
      routedCount++;
      slot = 1;
    } else {
      fallbackCount++;
    }
    for (const j of order) {
      if (slot >= BASELINE_K) break;
      if (slot > 0 && idx[row] === j) continue;
      idx[row + slot] = j;
      minutesOneWay[row + slot] = walkMinutesOneWay(dists[j]);
      slot++;
    }
  }
  return { sourceCount: n, sourceLon, sourceLat, idx, minutesOneWay, routedCount, fallbackCount };
}

export function buildTaps(
  h: Households,
  tapPoints: LngLat[],
  systemDailyL: number,
  graph: RoadGraph | null,
  hhSnap: Snap | null,
): Taps {
  const count = tapPoints.length;
  const lon = Float64Array.from(tapPoints, (p) => p[0]);
  const lat = Float64Array.from(tapPoints, (p) => p[1]);
  const minutesOneWay = new Float64Array(h.capacity * count).fill(Infinity);
  let routedCount = 0;
  let fallbackCount = 0;

  const tapSnap = graph ? snapPoints(graph, lon, lat, count) : null;
  for (let t = 0; t < count; t++) {
    let dist: Float64Array | null = null;
    if (graph && tapSnap && tapSnap.node[t] >= 0) {
      dist = boundedDistances(graph, [tapSnap.node[t]], [tapSnap.offsetM[t]], ROUTE_CUTOFF_M);
    }
    for (let i = 0; i < h.count; i++) {
      const node = hhSnap ? hhSnap.node[i] : -1;
      if (dist && node >= 0 && Number.isFinite(dist[node])) {
        minutesOneWay[i * count + t] = walkMinutesOneWay((hhSnap as Snap).offsetM[i] + dist[node]);
        routedCount++;
      } else {
        minutesOneWay[i * count + t] = straightMinutes(h, i, lon[t], lat[t]);
        fallbackCount++;
      }
    }
  }
  return {
    count,
    lon,
    lat,
    systemDailyL: Math.max(0, systemDailyL),
    perTapDailyL: perTapDailyLitres(),
    minutesOneWay,
    routedCount,
    fallbackCount,
  };
}

/** A spawned household sits a few metres from its parent, so it inherits the parent's distances. */
export function copyHouseholdRow(baseline: Baseline, taps: Taps, from: number, to: number): void {
  for (let s = 0; s < BASELINE_K; s++) {
    baseline.idx[to * BASELINE_K + s] = baseline.idx[from * BASELINE_K + s];
    baseline.minutesOneWay[to * BASELINE_K + s] = baseline.minutesOneWay[from * BASELINE_K + s];
  }
  for (let t = 0; t < taps.count; t++) {
    taps.minutesOneWay[to * taps.count + t] = taps.minutesOneWay[from * taps.count + t];
  }
}
```

How it works, for the implementer:
1. Households are processed nearest-tap-first (`order`), so a tap's capacity goes to the people closest to it.
2. A household's baseline round trip is twice the one-way minutes to its first working existing source in slots 0 to 2, or the no-source figure when none works.
3. Each working tap it can still fit into (both the tap's own daily limit and the system's daily yield times the seasonal factor) offers a round trip of twice the one-way minutes plus the tap's queue. It picks the lowest. If no tap beats the baseline, it stays on the baseline.
4. Queue time depends on who else chose the tap, so the rule runs twice: first with zero queue to find the loads, then again with queue times from those loads. The queue formula is the mean wait of a single server with fixed service time, `fill * u / (2 * (1 - u))`, capped.

```ts
// lib/popsim/assign.ts
/**
 * The household decision rule. Pure and deterministic: the same inputs give
 * the same assignment. Randomness lives one level up, in which sources are
 * working this week.
 */
import { BEHAVIOUR } from "@/lib/config/coefficients";
import type { Households } from "@/lib/popsim/households";
import { BASELINE_K, type Baseline, type Taps } from "@/lib/popsim/sources";

export const CHOICE_BASELINE = -1;
export const CHOICE_NONE = -2;

export type SourceState = { tapUp: Uint8Array; existingUp: Uint8Array; capacityFactor: number };

export type Assignment = {
  choice: Int32Array;
  minutes: Float64Array;
  baselineMinutes: Float64Array;
  tapLoadL: Float64Array;
  peopleServed: number;
  peopleUnder30Min: number;
  minutesSavedPerTrip: number;
  servedHouseholds: number;
  saturated: boolean;
};

const SATURATION_SHARE = 0.95;
const QUEUE_UTILISATION_CAP = 0.95;

export function allUp(taps: Taps, baseline: Baseline): SourceState {
  return {
    tapUp: new Uint8Array(taps.count).fill(1),
    existingUp: new Uint8Array(Math.max(1, baseline.sourceCount)).fill(1),
    capacityFactor: 1,
  };
}

/** Household indices sorted by their nearest tap, so capacity is handed out nearest-first. */
export function assignmentOrder(h: Households, taps: Taps): Int32Array {
  const best = new Float64Array(h.count);
  for (let i = 0; i < h.count; i++) {
    let b = Infinity;
    for (let t = 0; t < taps.count; t++) b = Math.min(b, taps.minutesOneWay[i * taps.count + t]);
    best[i] = b;
  }
  const order = Int32Array.from({ length: h.count }, (_, i) => i);
  return order.sort((a, b) => best[a] - best[b] || a - b);
}

function queueMinutes(loadL: number, perTapDailyL: number): number {
  if (perTapDailyL <= 0) return BEHAVIOUR.maxWaitMinutes.value;
  const u = Math.min(QUEUE_UTILISATION_CAP, loadL / perTapDailyL);
  const fill = BEHAVIOUR.containerFillMinutes.value;
  return Math.min(BEHAVIOUR.maxWaitMinutes.value, (fill * u) / (2 * (1 - u)));
}

function baselineRoundTrip(baseline: Baseline, state: SourceState, i: number): number {
  for (let s = 0; s < BASELINE_K; s++) {
    const j = baseline.idx[i * BASELINE_K + s];
    if (j < 0 || !state.existingUp[j]) continue;
    const one = baseline.minutesOneWay[i * BASELINE_K + s];
    if (Number.isFinite(one)) return 2 * one;
  }
  return BEHAVIOUR.noSourceRoundTripMinutes.value;
}

function pass(
  h: Households,
  baseline: Baseline,
  taps: Taps,
  state: SourceState,
  order: Int32Array,
  wait: Float64Array,
): Assignment {
  const choice = new Int32Array(h.count).fill(CHOICE_NONE);
  const minutes = new Float64Array(h.count);
  const baselineMinutes = new Float64Array(h.count);
  const tapLoadL = new Float64Array(taps.count);
  const systemCapL = taps.systemDailyL * Math.max(0, state.capacityFactor);
  let systemLoadL = 0;
  let peopleServed = 0;
  let peopleUnder30 = 0;
  let servedHouseholds = 0;
  let savedWeighted = 0;
  const limit = BEHAVIOUR.basicServiceRoundTripMinutes.value;

  for (let k = 0; k < order.length; k++) {
    const i = order[k];
    const demand = h.demandL[i];
    const pw = h.people[i] * h.weight[i];
    const base = baselineRoundTrip(baseline, state, i);
    baselineMinutes[i] = base;

    let bestTap = -1;
    let bestRt = base;
    for (let t = 0; t < taps.count; t++) {
      if (!state.tapUp[t]) continue;
      const one = taps.minutesOneWay[i * taps.count + t];
      if (!Number.isFinite(one)) continue;
      if (tapLoadL[t] + demand > taps.perTapDailyL) continue;
      if (systemLoadL + demand > systemCapL) continue;
      const rt = 2 * one + wait[t];
      if (rt < bestRt) {
        bestRt = rt;
        bestTap = t;
      }
    }

    if (bestTap >= 0) {
      choice[i] = bestTap;
      minutes[i] = bestRt;
      tapLoadL[bestTap] += demand;
      systemLoadL += demand;
      peopleServed += pw;
      servedHouseholds++;
      if (bestRt <= limit) peopleUnder30 += pw;
      savedWeighted += (base - bestRt) * pw;
    } else {
      choice[i] = base < BEHAVIOUR.noSourceRoundTripMinutes.value ? CHOICE_BASELINE : CHOICE_NONE;
      minutes[i] = base;
    }
  }

  const binding = Math.min(systemCapL, taps.count * taps.perTapDailyL);
  return {
    choice,
    minutes,
    baselineMinutes,
    tapLoadL,
    peopleServed,
    peopleUnder30Min: peopleUnder30,
    minutesSavedPerTrip: peopleServed > 0 ? savedWeighted / peopleServed : 0,
    servedHouseholds,
    saturated: binding > 0 && systemLoadL >= SATURATION_SHARE * binding,
  };
}

export function assign(
  h: Households,
  baseline: Baseline,
  taps: Taps,
  state: SourceState,
  order: Int32Array,
): Assignment {
  const zero = new Float64Array(taps.count);
  const first = pass(h, baseline, taps, state, order, zero);
  const wait = Float64Array.from(first.tapLoadL, (load) => queueMinutes(load, taps.perTapDailyL));
  return pass(h, baseline, taps, state, order, wait);
}
```

```ts
// lib/infrastructure/design.ts
/**
 * One costed conceptual design for a site: draw the layout, choose or force the
 * system type, cap the tap network to the population the system can supply,
 * and re-cost against what was actually drawn. The pipeline uses it for the
 * winner; the household simulation uses it for every site and type it tests.
 */
import type {
  CandidateFeatures,
  ClimateData,
  InfrastructureRecommendation,
  InfrastructureType,
  OsmData,
  PopulationEstimate,
} from "@/lib/types";
import { buildConceptualLayout, type ConceptualLayout } from "@/lib/geospatial/layout";
import { buildRecommendation } from "@/lib/infrastructure/select";

/** Planning figure: one community tap stand per this many people served. */
export const PEOPLE_PER_TAP = 250;

/** A mapped water point closer than this makes the site a rehabilitation candidate. */
const REHABILITATION_RADIUS_M = 600;

export type DesignInput = {
  site: { lon: number; lat: number };
  features: CandidateFeatures;
  osm: OsmData;
  climate: ClimateData;
  population: PopulationEstimate;
  serviceRadiusM: number;
  /** Force a system type instead of running the decision tree. */
  type?: InfrastructureType;
};

export function designProject(input: DesignInput): {
  layout: ConceptualLayout;
  recommendation: InfrastructureRecommendation;
} {
  const { site, features, osm, climate, population, serviceRadiusM } = input;
  const hasNearbyMappedWaterPoint =
    (features.distanceToMappedWaterPointM ?? Infinity) < REHABILITATION_RADIUS_M;

  const draft = buildConceptualLayout({
    site,
    features,
    osm,
    type: input.type ?? "solar_borehole",
    serviceRadiusM,
  });
  const first = buildRecommendation({
    features,
    climate,
    population,
    hasNearbyMappedWaterPoint,
    pipelineLengthM: draft.pipelineLengthM,
    tapStandCount: draft.tapStandCount,
    forceType: input.type,
  });

  const layout = buildConceptualLayout({
    site,
    features,
    osm,
    type: first.type,
    serviceRadiusM,
    maxTaps: Math.ceil(Math.max(1, first.peopleServedHigh) / PEOPLE_PER_TAP),
  });
  const recommendation = buildRecommendation({
    features,
    climate,
    population,
    hasNearbyMappedWaterPoint,
    pipelineLengthM: layout.pipelineLengthM,
    tapStandCount: layout.tapStandCount,
    forceType: first.type,
  });
  return { layout, recommendation };
}
```

```ts
// lib/popsim/evaluate.ts
/**
 * Stage 2 of the household simulation: one deterministic evaluation of a
 * project (a site and a system type) with every source working, in year one.
 * Cheap enough to run for every viable site and every type.
 */
import type {
  Candidate,
  ClimateData,
  InfrastructureType,
  OsmData,
  SimulationProject,
  TownRef,
} from "@/lib/types";
import { BEHAVIOUR } from "@/lib/config/coefficients";
import { estimatePopulationServed } from "@/lib/geospatial/population";
import { designProject } from "@/lib/infrastructure/design";
import { allUp, assign, assignmentOrder, type Assignment } from "@/lib/popsim/assign";
import { planarScale } from "@/lib/popsim/geo";
import { buildHouseholds, type ExtraHousehold, type Households } from "@/lib/popsim/households";
import { buildRoadGraph, snapPoints, type RoadGraph, type Snap } from "@/lib/popsim/roads";
import { buildBaseline, buildTaps, type Baseline, type Taps } from "@/lib/popsim/sources";

export type EvalContext = {
  town: TownRef;
  osm: OsmData;
  climate: ClimateData;
  households: Households;
  baseline: Baseline;
  graph: RoadGraph | null;
  hhSnap: Snap | null;
  serviceRadiusM: number;
};

export type Evaluated = {
  project: SimulationProject;
  taps: Taps;
  order: Int32Array;
  assignment: Assignment;
  monthlyAvailability: number[];
};

function round1(v: number): number {
  return Math.round(v * 10) / 10;
}

export function buildEvalContext(args: {
  town: TownRef;
  osm: OsmData;
  climate: ClimateData;
  serviceRadiusM: number;
  extraHouseholds?: ExtraHousehold[];
}): EvalContext {
  const { town, osm, climate, serviceRadiusM } = args;
  const households = buildHouseholds(osm, args.extraHouseholds ?? []);
  const graph = buildRoadGraph(osm.roads, planarScale(town.center[1]));
  const hhSnap = graph ? snapPoints(graph, households.lon, households.lat, households.count) : null;
  const baseline = buildBaseline(households, osm.waterPoints, graph, hhSnap);
  return { town, osm, climate, households, baseline, graph, hhSnap, serviceRadiusM };
}

/** Seasonal capacity factor per month. Only rainwater follows the rain; everything else is 1. */
export function monthlyAvailability(type: InfrastructureType, climate: ClimateData): number[] {
  if (type !== "rainwater_harvesting") return Array.from({ length: 12 }, () => 1);
  const monthly = climate.monthlyRainfallMmDay.length === 12 ? climate.monthlyRainfallMmDay : Array(12).fill(0);
  const mean = monthly.reduce((s, v) => s + Math.max(0, v), 0) / 12;
  const floor = BEHAVIOUR.minSeasonalAvailability.value;
  if (!(mean > 0)) return Array.from({ length: 12 }, () => floor);
  return monthly.map((v) => Math.min(1, Math.max(floor, Math.max(0, v) / mean)));
}

export function evaluateProject(
  ctx: EvalContext,
  candidate: Candidate,
  type: InfrastructureType,
): Evaluated {
  const population = estimatePopulationServed({
    town: ctx.town,
    osm: ctx.osm,
    winnerFeatures: candidate.features,
    totalBuildingsInArea: ctx.osm.buildings.length,
    serviceRadiusM: ctx.serviceRadiusM,
  });
  const { layout, recommendation } = designProject({
    site: { lon: candidate.lon, lat: candidate.lat },
    features: candidate.features,
    osm: ctx.osm,
    climate: ctx.climate,
    population,
    serviceRadiusM: ctx.serviceRadiusM,
    type,
  });

  const dailyCapacityLiters = recommendation.output.dailyLitersHigh;
  const taps = buildTaps(ctx.households, layout.taps, dailyCapacityLiters, ctx.graph, ctx.hhSnap);
  const order = assignmentOrder(ctx.households, taps);
  const assignment = assign(ctx.households, ctx.baseline, taps, allUp(taps, ctx.baseline), order);

  const costMid = (recommendation.cost.totalLow + recommendation.cost.totalHigh) / 2;
  const project: SimulationProject = {
    id: `${candidate.id}:${type}`,
    candidateId: candidate.id,
    lon: candidate.lon,
    lat: candidate.lat,
    type,
    label: recommendation.label,
    costLow: recommendation.cost.totalLow,
    costHigh: recommendation.cost.totalHigh,
    dailyCapacityLiters,
    tapCount: taps.count,
    peopleServed: Math.round(assignment.peopleServed),
    peopleUnder30Min: Math.round(assignment.peopleUnder30Min),
    minutesSavedPerTrip: round1(assignment.minutesSavedPerTrip),
    costPerPersonServed: round1(costMid / Math.max(1, assignment.peopleServed)),
    futures: null,
  };
  return { project, taps, order, assignment, monthlyAvailability: monthlyAvailability(type, ctx.climate) };
}
```

What one future does, week by week:
1. At each year boundary, spawn `round(count * growth)` households. Each child copies a random existing parent, offset by up to 25 m, and inherits its distances. The assignment order is rebuilt.
2. Each working tap fails with probability `failProject`; a failed one comes back after `int(repairLow, repairHigh)` weeks. Existing sources do the same with `failExisting`.
3. The seasonal factor for the month scales the system's daily yield.
4. The decision rule runs. Year-one weeks accumulate the served figures; every week records whether the taps were saturated.

```ts
// lib/popsim/stats.ts
import type { SimulationMetric } from "@/lib/types";

/** Linear-interpolation quantile on a sorted copy. Empty input gives 0. */
export function quantile(values: number[], p: number): number {
  if (values.length === 0) return 0;
  const sorted = values.slice().sort((a, b) => a - b);
  const pos = Math.min(1, Math.max(0, p)) * (sorted.length - 1);
  const lo = Math.floor(pos);
  const hi = Math.ceil(pos);
  return sorted[lo] + (sorted[hi] - sorted[lo]) * (pos - lo);
}

function round1(v: number): number {
  return Math.round(v * 10) / 10;
}

export function summarise(values: number[]): SimulationMetric {
  return {
    p10: round1(quantile(values, 0.1)),
    p50: round1(quantile(values, 0.5)),
    p90: round1(quantile(values, 0.9)),
  };
}
```

```ts
// lib/popsim/simulate.ts
/**
 * Stage 3 of the household simulation: one seeded future for one project.
 * Everything random draws from one generator seeded per future, so a future
 * is reproducible by its seed. The shared context is never mutated.
 */
import { BEHAVIOUR } from "@/lib/config/coefficients";
import { assign, assignmentOrder, type SourceState } from "@/lib/popsim/assign";
import type { EvalContext, Evaluated } from "@/lib/popsim/evaluate";
import { planarScale } from "@/lib/popsim/geo";
import { addHousehold, cloneHouseholds } from "@/lib/popsim/households";
import { createRng } from "@/lib/popsim/rng";
import { copyHouseholdRow, type Baseline, type Taps } from "@/lib/popsim/sources";

export type Rates = {
  failExisting: number;
  failProject: number;
  repairLow: number;
  repairHigh: number;
  growth: number;
};

export function defaultRates(): Rates {
  return {
    failExisting: BEHAVIOUR.weeklyFailureProbability.existing,
    failProject: BEHAVIOUR.weeklyFailureProbability.project,
    repairLow: BEHAVIOUR.repairWeeks.low,
    repairHigh: BEHAVIOUR.repairWeeks.high,
    growth: BEHAVIOUR.annualGrowthRate.value,
  };
}

export const WEEKS_PER_YEAR = 52;
/** New households are placed within this distance of their parent. */
const SPAWN_JITTER_M = 25;

export type FutureOptions = { weeks: number; rates: Rates };

export type FutureOutcome = {
  peopleServed: number;
  peopleUnder30Min: number;
  minutesSavedPerTrip: number;
  capacityYear: number | null;
  householdsAtEnd: number;
  weeksProjectDown: number;
};

function cloneBaseline(b: Baseline): Baseline {
  return { ...b, idx: b.idx.slice(), minutesOneWay: b.minutesOneWay.slice() };
}

function cloneTaps(t: Taps): Taps {
  return { ...t, minutesOneWay: t.minutesOneWay.slice() };
}

/** Advance one set of sources by a week: fail working ones, count down repairs. */
function tick(
  up: Uint8Array,
  repairLeft: Int32Array,
  failProbability: number,
  rates: Rates,
  rng: ReturnType<typeof createRng>,
): void {
  for (let i = 0; i < up.length; i++) {
    if (up[i]) {
      if (rng.next() < failProbability) {
        up[i] = 0;
        repairLeft[i] = rng.int(rates.repairLow, rates.repairHigh);
      }
    } else if (--repairLeft[i] <= 0) {
      up[i] = 1;
    }
  }
}

export function simulateFuture(
  ev: Evaluated,
  ctx: EvalContext,
  seed: number,
  opts: FutureOptions,
): FutureOutcome {
  const rng = createRng(seed);
  const h = cloneHouseholds(ctx.households);
  const baseline = cloneBaseline(ctx.baseline);
  const taps = cloneTaps(ev.taps);
  let order = ev.order.slice();

  const state: SourceState = {
    tapUp: new Uint8Array(taps.count).fill(1),
    existingUp: new Uint8Array(Math.max(1, baseline.sourceCount)).fill(1),
    capacityFactor: 1,
  };
  const tapRepair = new Int32Array(taps.count);
  const existingRepair = new Int32Array(state.existingUp.length);

  const years = Math.max(1, Math.ceil(opts.weeks / WEEKS_PER_YEAR));
  const saturatedWeeks = new Int32Array(years);
  let sumServed = 0;
  let sumUnder30 = 0;
  let sumSavedWeighted = 0;
  let weeksProjectDown = 0;
  const scale = planarScale(ctx.town.center[1]);

  for (let w = 0; w < opts.weeks; w++) {
    const year = Math.floor(w / WEEKS_PER_YEAR);

    if (w > 0 && w % WEEKS_PER_YEAR === 0 && opts.rates.growth > 0) {
      const spawn = Math.round(h.count * opts.rates.growth);
      const parents = h.count;
      for (let s = 0; s < spawn; s++) {
        const parent = rng.int(0, parents - 1);
        const dx = ((rng.next() - 0.5) * 2 * SPAWN_JITTER_M) / scale.mPerDegLon;
        const dy = ((rng.next() - 0.5) * 2 * SPAWN_JITTER_M) / scale.mPerDegLat;
        const child = addHousehold(h, h.lon[parent] + dx, h.lat[parent] + dy, h.weight[parent]);
        if (child >= 0) copyHouseholdRow(baseline, taps, parent, child);
      }
      order = assignmentOrder(h, taps);
    }

    tick(state.tapUp, tapRepair, opts.rates.failProject, opts.rates, rng);
    if (baseline.sourceCount > 0) tick(state.existingUp, existingRepair, opts.rates.failExisting, opts.rates, rng);

    const month = Math.floor(((w % WEEKS_PER_YEAR) / WEEKS_PER_YEAR) * 12);
    state.capacityFactor = ev.monthlyAvailability[month] ?? 1;

    const a = assign(h, baseline, taps, state, order);
    if (a.saturated) saturatedWeeks[year]++;
    let anyDown = false;
    for (let t = 0; t < taps.count; t++) if (!state.tapUp[t]) anyDown = true;
    if (anyDown) weeksProjectDown++;

    if (w < WEEKS_PER_YEAR) {
      sumServed += a.peopleServed;
      sumUnder30 += a.peopleUnder30Min;
      sumSavedWeighted += a.minutesSavedPerTrip * a.peopleServed;
    }
  }

  const firstYearWeeks = Math.min(opts.weeks, WEEKS_PER_YEAR);
  let capacityYear: number | null = null;
  for (let y = 0; y < years; y++) {
    const weeksInYear = Math.min(WEEKS_PER_YEAR, opts.weeks - y * WEEKS_PER_YEAR);
    if (saturatedWeeks[y] > weeksInYear / 2) {
      capacityYear = y + 1;
      break;
    }
  }

  return {
    peopleServed: sumServed / firstYearWeeks,
    peopleUnder30Min: sumUnder30 / firstYearWeeks,
```

```ts
 * The household simulation, end to end.
 *
 *   every viable site x every system type  ->  stage-2 evaluation (deterministic)
 *   rank by cost per person served          ->  shortlist
 *   shortlist x K seeded futures            ->  stage-3 distributions, pass counts
 *   most passes, then cheapest per person   ->  recommendation

function byCostThenServed(a: SimulationProject, b: SimulationProject): number {
  return (
    a.costPerPersonServed - b.costPerPersonServed ||
    b.peopleServed - a.peopleServed ||
    (a.id < b.id ? -1 : a.id > b.id ? 1 : 0)
  );
}

function byPassesThenCost(a: SimulationProject, b: SimulationProject): number {
  const pa = a.futures?.passed ?? -1;
  const pb = b.futures?.passed ?? -1;
  return pb - pa || byCostThenServed(a, b);
}

function householdOutcomes(ctx: EvalContext, ev: Evaluated): HouseholdOutcome[] {
  const h = ctx.households;
  const a = ev.assignment;
  const out: HouseholdOutcome[] = [];
  for (let i = 0; i < h.count; i++) {
    const c = a.choice[i];
    let sourceLon = h.lon[i];
    let sourceLat = h.lat[i];
    if (c >= 0) {
      sourceLon = ev.taps.lon[c];
      sourceLat = ev.taps.lat[c];
    } else if (c === CHOICE_BASELINE) {
      const j = ctx.baseline.idx[i * BASELINE_K];
      if (j >= 0) {
        sourceLon = ctx.baseline.sourceLon[j];
        sourceLat = ctx.baseline.sourceLat[j];
      }
    }
    out.push({
      lon: h.lon[i],
      lat: h.lat[i],
      people: Math.round(h.people[i] * h.weight[i] * 10) / 10,
      served: c >= 0,
      baselineMinutes: Math.round(a.baselineMinutes[i] * 10) / 10,
      projectMinutes: Math.round(a.minutes[i] * 10) / 10,
      sourceLon,
      sourceLat,
    });
  }
  return out;
}

    householdCount: 0,
    peopleTotal: 0,
    sampleRatio: 1,
    evaluated: 0,
    shortlisted: 0,
    futuresPerProject: 0,
    weeksPerFuture: 0,
    projects: [],
    recommendedId: null,
    households: [],
    assumptions: [reason],
  };

export async function runSimulation(
  input: SimulationInput,
  opts: SimulationOptions = LIVE_OPTIONS,
  emit: SimulationEmit = () => {},
): Promise<SimulationResult> {
  const ctx = buildEvalContext({
    town: input.town,
    osm: input.osm,
    climate: input.climate,
    serviceRadiusM: input.serviceRadiusM,
    extraHouseholds: input.extraHouseholds,
  });
  if (ctx.households.count === 0) {
    return emptyResult("No mapped buildings near this town, so no households could be simulated. Absence of mapping is not evidence of absence of people.");
  }

  const byId = new Map(input.candidates.map((c) => [c.id, c]));
  const sites: Candidate[] = [];
  for (const id of input.ranked) {
    if (sites.length >= opts.maxSites) break;
    const c = byId.get(id);
    if (c && !c.excluded) sites.push(c);
  }
  emit(`${ctx.households.count.toLocaleString("en-US")} households · ${sites.length} sites x ${ALL_TYPES.length} systems`, ctx.households.count);

  // Stage 2.
  const evaluated: Evaluated[] = [];
  for (const site of sites) {
    for (const type of ALL_TYPES) {
      evaluated.push(evaluateProject(ctx, site, type));
      if (evaluated.length % YIELD_EVERY === 0) await yieldToEventLoop();
    }
  }
  const viable = evaluated.filter((e) => e.project.peopleServed >= opts.minPeopleServed);
  const pool = (viable.length > 0 ? viable : evaluated).sort((a, b) => byCostThenServed(a.project, b.project));
  const shortlist = pool.slice(0, opts.shortlist);
  emit(`Simulating ${shortlist.length} projects x ${opts.futures} futures`, shortlist.length);

  // Stage 3.
  const years = Math.ceil(opts.weeks / 52);
  for (const ev of shortlist) {
    const designed = ev.assignment.peopleServed;
    const outcomes = Array.from({ length: opts.futures }, (_, k) =>
      simulateFuture(ev, ctx, k + 1, { weeks: opts.weeks, rates: input.rates }),
    );
    const passed = outcomes.filter((o) => o.peopleServed >= BEHAVIOUR.passThreshold.value * designed).length;
    const capacityP50 = quantile(outcomes.map((o) => o.capacityYear ?? years + 1), 0.5);
    ev.project.futures = {
      run: opts.futures,
      passed,
      peopleServed: summarise(outcomes.map((o) => o.peopleServed)),
      peopleUnder30Min: summarise(outcomes.map((o) => o.peopleUnder30Min)),
      minutesSavedPerTrip: summarise(outcomes.map((o) => o.minutesSavedPerTrip)),
      capacityYear: capacityP50 > years ? null : Math.round(capacityP50),
    };
    await yieldToEventLoop();
  }

  const shortlisted = shortlist.map((e) => e.project).sort(byPassesThenCost);
  const rest = evaluated
    .filter((e) => !e.project.futures)
    .map((e) => e.project)
    .sort(byCostThenServed);
  const projects = [...shortlisted, ...rest];
  const recommended = shortlist.find((e) => e.project.id === shortlisted[0]?.id) ?? null;

  if (recommended) {
    const f = recommended.project.futures;
    emit(`Best: ${recommended.project.label} · held in ${f?.passed ?? 0}/${opts.futures} futures`, opts.futures);
  }

  return {
    version: 1,
    householdCount: ctx.households.count,
    peopleTotal: Math.round(ctx.households.peopleTotal),
    sampleRatio: ctx.households.sampleRatio,
    evaluated: evaluated.length,
    shortlisted: shortlist.length,
    futuresPerProject: opts.futures,
    weeksPerFuture: opts.weeks,
    projects,
    recommendedId: recommended?.project.id ?? null,
    households: recommended ? householdOutcomes(ctx, recommended) : [],
    assumptions: assumptions(ctx, input, opts),
  };
}
```

```ts
  }));
  const content = await callOpenAI(
    [
      { role: "system", content: SYSTEM },
      { role: "user", content: `Town: ${town.displayName}.\n\n${JSON.stringify(docs)}` },
    ],
    20_000,
    { type: "json_schema", json_schema: { name: "town_rates", strict: true, schema: RESPONSE_SCHEMA } },
  );
  if (!content) return null;
  try {
    const parsed = Schema.safeParse(JSON.parse(content));
    return parsed.success ? parsed.data : null;
  } catch {
    return null;
  }
}

function cite(field: Field, extracted: ExtractedRates, raw: RawEvidence[]): string {
  const src = extracted.sources.find((s) => s.field === field);
  const doc = src ? raw[src.index] : undefined;
  if (!src || !doc) return "source sentence not returned";
  return `"${src.quote.slice(0, 200)}" (${doc.title}, ${doc.url})`;
}

export function deriveRates(extracted: ExtractedRates | null, raw: RawEvidence[]): TownRates {
  const rates = defaultRates();
  if (!extracted) {
    return {
      rates,
      notes: ["Breakdown, repair and growth rates are labelled planning defaults; no town-specific figures were found in the retrieved sources."],
    };
  }
  const notes: string[] = [];

  let meanRepair = (rates.repairLow + rates.repairHigh) / 2;
  if (extracted.repairWeeks !== null && Number.isFinite(extracted.repairWeeks)) {
    meanRepair = clamp(extracted.repairWeeks, BOUNDS.repairWeeks.low, BOUNDS.repairWeeks.high);
    rates.repairLow = Math.max(1, Math.round(meanRepair * 0.5));
    rates.repairHigh = Math.min(52, Math.round(meanRepair * 1.5));
    notes.push(`Repairs take ${rates.repairLow}-${rates.repairHigh} weeks, from ${cite("repairWeeks", extracted, raw)}.`);
  }

  if (extracted.nonFunctionalShare !== null && Number.isFinite(extracted.nonFunctionalShare)) {
    const s = clamp(extracted.nonFunctionalShare, BOUNDS.share.low, BOUNDS.share.high);
    const p = s / (meanRepair * (1 - s));
    const ratio = BEHAVIOUR.weeklyFailureProbability.project / BEHAVIOUR.weeklyFailureProbability.existing;
    rates.failExisting = p;
    rates.failProject = p * ratio;
    notes.push(`Weekly failure probability ${(p * 100).toFixed(2)}% for existing points (half that for the new system), derived from a ${Math.round(s * 100)}% non-functional share in ${cite("nonFunctionalShare", extracted, raw)}.`);
  }

  if (extracted.annualGrowthRate !== null && Number.isFinite(extracted.annualGrowthRate)) {
    rates.growth = clamp(extracted.annualGrowthRate, BOUNDS.growth.low, BOUNDS.growth.high);
    notes.push(`Households grow ${(rates.growth * 100).toFixed(1)}% a year, from ${cite("annualGrowthRate", extracted, raw)}.`);
  }

  if (notes.length === 0) {
    notes.push("Breakdown, repair and growth rates are labelled planning defaults; the retrieved sources contained no usable figures.");
  }
  return { rates, notes };
}
```

What it does and does not do:
- Looks at the tiles within 600 m of the top three ranked sites, sparsest first, at most `MAX_TILES`. This is where a missing neighbourhood changes the answer. It does not survey the whole town; the notes say so.
- For each tile the model returns a structure count and a confidence. Code compares it with the expected real count (`osmCount * sampleRatio`). - Without `OPENAI_API_KEY` it returns nothing and a note. It never throws.

```ts
// lib/providers/imagery.ts
/**
 * Satellite tiles from the same Esri World Imagery service the map draws.
 * Slippy-map tile maths; no key required.
 */
export const IMAGERY_TILE_URL =
  "https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer/tile/{z}/{y}/{x}";

const TIMEOUT_MS = 10_000;

export function tileFor(lon: number, lat: number, z: number): { x: number; y: number } {
  const n = 2 ** z;
  const x = Math.floor(((lon + 180) / 360) * n);
  const latRad = (lat * Math.PI) / 180;
  const y = Math.floor(((1 - Math.log(Math.tan(latRad) + 1 / Math.cos(latRad)) / Math.PI) / 2) * n);
  return { x: Math.min(n - 1, Math.max(0, x)), y: Math.min(n - 1, Math.max(0, y)) };
}

function tileLat(y: number, z: number): number {
  const n = Math.PI - (2 * Math.PI * y) / 2 ** z;
  return (180 / Math.PI) * Math.atan(0.5 * (Math.exp(n) - Math.exp(-n)));
}

export function tileBounds(x: number, y: number, z: number): [number, number, number, number] {
  const n = 2 ** z;
  const west = (x / n) * 360 - 180;
  const east = ((x + 1) / n) * 360 - 180;
  return [west, tileLat(y + 1, z), east, tileLat(y, z)];
}

export async function fetchTilePng(z: number, x: number, y: number): Promise<Buffer | null> {
  const url = IMAGERY_TILE_URL.replace("{z}", String(z)).replace("{y}", String(y)).replace("{x}", String(x));
  const ctrl = new AbortController();
  const timer = setTimeout(() => ctrl.abort(), TIMEOUT_MS);
  try {
    const res = await fetch(url, { signal: ctrl.signal, cache: "no-store" });
    if (!res.ok) return null;
    return Buffer.from(await res.arrayBuffer());
  } catch {
    return null;
  } finally {
    clearTimeout(timer);
  }
}
```

```ts
// lib/popsim/vision.ts
/**
 * Where OpenStreetMap is thin, count roofs in the satellite imagery instead.
 *
 * The model's only job is to count structures in one tile and say how sure it
 * is. Which tiles to look at, whether the count is different enough to act on,
 * and where synthetic households go are all code, and every answer is cached
 * on disk so a re-run is reproducible without another call.
 */
import { promises as fs } from "node:fs";
import path from "node:path";
import { z as zod } from "zod";
import type { Candidate, OsmData, TownRef } from "@/lib/types";
import { fetchTilePng, tileBounds, tileFor } from "@/lib/providers/imagery";
import { isLlmConfigured, llmModel } from "@/lib/evidence/llm";
import type { ExtraHousehold } from "@/lib/popsim/households";
import { createRng } from "@/lib/popsim/rng";

export const VISION_ZOOM = 17;
export const MAX_TILES = 24;
/** Tiles this far from a top site are considered. */
const SITE_RADIUS_M = 600;
const TOP_SITES = 3;
/** Act only when the model sees at least this multiple of the expected real count. */
const MIN_RATIO = 1.5;
const MIN_CONFIDENCE = 0.5;
/** More than this in one tile is not a count, it is a hallucination. */
const MAX_STRUCTURES = 600;
const CONCURRENCY = 6;
const DEFAULT_CACHE_DIR = path.join(process.cwd(), "data", "cache", "vision");

export type VisionCorrection = {
  z: number; x: number; y: number;
  osmCount: number; expectedReal: number; seenCount: number; confidence: number; added: number;
};
export type TileCounter = (png: Buffer, osmCount: number) => Promise<{ structures: number; confidence: number } | null>;
export type VisionDeps = { count: TileCounter; fetchTile: typeof fetchTilePng; cacheDir: string | null };
export type VisionResult = { extra: ExtraHousehold[]; corrections: VisionCorrection[]; notes: string[]; tilesChecked: number };

const Answer = zod.object({ structures: zod.number().int().min(0), confidence: zod.number().min(0).max(1) });

/** Ask the model to count. Kept separate from lib/evidence/llm.ts because it sends an image. */
async function countWithOpenAI(png: Buffer, osmCount: number): Promise<{ structures: number; confidence: number } | null> {
  const key = process.env.OPENAI_API_KEY?.trim();
  if (!key) return null;
  const ctrl = new AbortController();
  const timer = setTimeout(() => ctrl.abort(), 30_000);
  try {
    const res = await fetch("https://api.openai.com/v1/chat/completions", {
      method: "POST",
      signal: ctrl.signal,
      cache: "no-store",
      headers: { "Content-Type": "application/json", Authorization: `Bearer ${key}` },
      body: JSON.stringify({
        model: llmModel(),
        temperature: 0,
        response_format: {
          type: "json_schema",
          json_schema: {
            name: "tile_count",
            strict: true,
            schema: {
              type: "object",
              additionalProperties: false,
              required: ["structures", "confidence"],
              properties: { structures: { type: "integer" }, confidence: { type: "number" } },
            },
          },
        },
        messages: [
          {
            role: "system",
            content:
              "You count buildings in one satellite image tile of an African town. Count every roofed structure you can see, including small dwellings. " +
              "Return the count and a confidence from 0 to 1 that reflects cloud, blur, and how clearly roofs are separable. Do not use the map count except as context.",
          },
          {
            role: "user",
            content: [
              { type: "text", text: `OpenStreetMap has ${osmCount} building(s) mapped in this tile. Count the structures you actually see.` },
              { type: "image_url", image_url: { url: `data:image/png;base64,${png.toString("base64")}`, detail: "high" } },
            ],
          },
        ],
      }),
    });
    if (!res.ok) return null;
    const data = (await res.json()) as { choices?: { message?: { content?: string } }[] };
    const parsed = Answer.safeParse(JSON.parse(data.choices?.[0]?.message?.content ?? "null"));
    return parsed.success ? parsed.data : null;
  } catch {
    return null;
  } finally {
    clearTimeout(timer);
  }
}

function key(x: number, y: number): string {
  return `${x},${y}`;
}

/** Tiles within SITE_RADIUS_M of the top-ranked sites, sparsest first, capped. */
export function selectTiles(
  osm: OsmData,
  candidates: Candidate[],
  ranked: string[],
): { x: number; y: number; osmCount: number }[] {
  const byId = new Map(candidates.map((c) => [c.id, c]));
  const counts = new Map<string, number>();
  for (const b of osm.buildings) {
    if (!Number.isFinite(b.lon) || !Number.isFinite(b.lat)) continue;
    const t = tileFor(b.lon, b.lat, VISION_ZOOM);
    counts.set(key(t.x, t.y), (counts.get(key(t.x, t.y)) ?? 0) + 1);
  }

  const chosen = new Map<string, { x: number; y: number; osmCount: number; distM: number }>();
  for (const id of ranked.slice(0, TOP_SITES)) {
    const site = byId.get(id);
    if (!site) continue;
    const mPerDegLat = 111_320;
    const mPerDegLon = Math.max(1, mPerDegLat * Math.cos((site.lat * Math.PI) / 180));
    const dLat = SITE_RADIUS_M / mPerDegLat;
    const dLon = SITE_RADIUS_M / mPerDegLon;
    const a = tileFor(site.lon - dLon, site.lat + dLat, VISION_ZOOM);
    const b = tileFor(site.lon + dLon, site.lat - dLat, VISION_ZOOM);
    for (let x = a.x; x <= b.x; x++) {
      for (let y = a.y; y <= b.y; y++) {
        const [w, s, e, n] = tileBounds(x, y, VISION_ZOOM);
        const cx = (w + e) / 2;
        const cy = (s + n) / 2;
        const distM = Math.hypot((cx - site.lon) * mPerDegLon, (cy - site.lat) * mPerDegLat);
        if (distM > SITE_RADIUS_M) continue;
        const k = key(x, y);
        const prev = chosen.get(k);
        if (!prev || distM < prev.distM) chosen.set(k, { x, y, osmCount: counts.get(k) ?? 0, distM });
      }
    }
  }
  return [...chosen.values()]
    .sort((p, q) => p.osmCount - q.osmCount || p.distM - q.distM || p.x - q.x || p.y - q.y)
    .slice(0, MAX_TILES)
    .map(({ x, y, osmCount }) => ({ x, y, osmCount }));
}

/** n points on a jittered grid inside the tile. Seeded by the tile so it never moves between runs. */
export function placeSynthetic(x: number, y: number, z: number, n: number): { lon: number; lat: number }[] {
  const [w, s, e, north] = tileBounds(x, y, z);
  const rng = createRng((x * 73856093) ^ (y * 19349663) ^ z);
  const side = Math.max(1, Math.ceil(Math.sqrt(n)));
  const out: { lon: number; lat: number }[] = [];
  for (let i = 0; i < n; i++) {
    const cx = (i % side + 0.5 + (rng.next() - 0.5) * 0.6) / side;
    const cy = (Math.floor(i / side) + 0.5 + (rng.next() - 0.5) * 0.6) / side;
    out.push({ lon: w + (e - w) * Math.min(1, Math.max(0, cx)), lat: s + (north - s) * Math.min(1, Math.max(0, cy)) });
  }
  return out;
}

async function readCache(dir: string | null, x: number, y: number) {
  if (!dir) return null;
  try {
    const raw = await fs.readFile(path.join(dir, String(VISION_ZOOM), String(x), `${y}.json`), "utf8");
    const parsed = Answer.safeParse(JSON.parse(raw));
    return parsed.success ? parsed.data : null;
  } catch {
    return null;
  }
}

async function writeCache(dir: string | null, x: number, y: number, answer: { structures: number; confidence: number }) {
  if (!dir) return;
  try {
    const p = path.join(dir, String(VISION_ZOOM), String(x));
    await fs.mkdir(p, { recursive: true });
    await fs.writeFile(path.join(p, `${y}.json`), JSON.stringify({ ...answer, model: llmModel(), at: new Date().toISOString() }), "utf8");
  } catch {
    /* read-only filesystem: fine, just uncached */
  }
}

export async function visionHouseholds(
  args: { town: TownRef; osm: OsmData; candidates: Candidate[]; ranked: string[] },
  deps: Partial<VisionDeps> = {},
): Promise<VisionResult> {
  const d: VisionDeps = { count: countWithOpenAI, fetchTile: fetchTilePng, cacheDir: DEFAULT_CACHE_DIR, ...deps };
  const usingDefaultCounter = !deps.count;
  if (usingDefaultCounter && !isLlmConfigured()) {
    return { extra: [], corrections: [], notes: ["Satellite building check not configured (no OPENAI_API_KEY); households come from OpenStreetMap only."], tilesChecked: 0 };
  }
  const tiles = selectTiles(args.osm, args.candidates, args.ranked);
  const sampleRatio = Number.isFinite(args.osm.buildingSampleRatio) ? Math.max(1, args.osm.buildingSampleRatio) : 1;
  const corrections: VisionCorrection[] = [];
  const extra: ExtraHousehold[] = [];
  let tilesChecked = 0;

  const work = tiles.map((t) => async () => {
    let answer = await readCache(d.cacheDir, t.x, t.y);
    if (!answer) {
      const png = await d.fetchTile(VISION_ZOOM, t.x, t.y);
      if (!png) return;
      answer = await d.count(png, t.osmCount);
      if (!answer) return;
      await writeCache(d.cacheDir, t.x, t.y, answer);
    }
    tilesChecked++;
    const seen = Math.min(MAX_STRUCTURES, Math.max(0, Math.round(answer.structures)));
    const expectedReal = t.osmCount * sampleRatio;
    const act = answer.confidence >= MIN_CONFIDENCE && seen >= MIN_RATIO * Math.max(1, expectedReal);
    const added = act ? Math.max(0, Math.round(seen - expectedReal)) : 0;
    corrections.push({ z: VISION_ZOOM, x: t.x, y: t.y, osmCount: t.osmCount, expectedReal, seenCount: seen, confidence: answer.confidence, added });
    if (added > 0) for (const p of placeSynthetic(t.x, t.y, VISION_ZOOM, added)) extra.push({ ...p, weight: 1 });
  });

  // Bounded concurrency without a dependency.
  let next = 0;
  await Promise.all(
    Array.from({ length: Math.min(CONCURRENCY, work.length) }, async () => {
      while (next < work.length) await work[next++]();
    }),
  );
  corrections.sort((a, b) => a.x - b.x || a.y - b.y);

  const addedTotal = extra.length;
  const notes = [
    `Satellite check: ${tilesChecked} imagery tiles within ${SITE_RADIUS_M} m of the top ${TOP_SITES} sites were counted by ${llmModel()}; ${addedTotal} unmapped households were added in ${corrections.filter((c) => c.added > 0).length} tiles where it saw at least ${MIN_RATIO}x the mapped count with confidence ${MIN_CONFIDENCE} or higher. The rest of the town relies on OpenStreetMap coverage.`,
  ];
  return { extra, corrections, notes, tilesChecked };
}
```

```ts
// scripts/recache.ts
/**
 * Re-run the preset towns live and refresh both the run cache and the bundled
 * demo snapshots. Run with the keys loaded:
 *   node --env-file=.env --import tsx scripts/recache.ts [slug ...]
 */
import { promises as fs } from "node:fs";
import path from "node:path";
import { runAnalysis } from "@/lib/pipeline";
import { saveRun } from "@/lib/cache/cache";
import { PRECOMPUTE_OPTIONS } from "@/lib/popsim/scenarios";
import type { AnalysisEvent, AnalysisRun, TrackId } from "@/lib/types";

const DEFAULT_SLUGS = ["kisumu-kenya", "gulu-uganda", "tamale-ghana"];
const RUNS = path.join(process.cwd(), "data", "runs");
const DEMO = path.join(process.cwd(), "data", "demo");

async function recache(slug: string): Promise<void> {
  const previous = JSON.parse(await fs.readFile(path.join(RUNS, `${slug}.json`), "utf8")) as AnalysisRun;
  const events: AnalysisEvent[] = [];
  let seq = 0;
  const emit = (track: TrackId, message: string, status: AnalysisEvent["status"], sourceCount?: number) => {
    events.push({
      id: `e${String(seq++).padStart(3, "0")}`,
      track,
      message,
      ts: Date.now(),
      status,
      ...(sourceCount !== undefined ? { sourceCount } : {}),
    });
    console.log(`[${slug}] ${track}: ${message}`);
  };

  const started = Date.now();
  const run = await runAnalysis(previous.town, emit, { simulation: PRECOMPUTE_OPTIONS });
  run.events = events;
  if (!(await saveRun(run))) throw new Error(`could not save ${slug}`);
  await fs.copyFile(path.join(RUNS, `${slug}.json`), path.join(DEMO, `${slug}.json`));
  if (slug === "kisumu-kenya") await fs.copyFile(path.join(RUNS, `${slug}.json`), path.join(DEMO, "default.json"));

  const sim = run.simulation;
  const best = sim?.projects[0];
  console.log(
    `[${slug}] done in ${Math.round((Date.now() - started) / 1000)} s · evidence ${run.dataSources.find((d) => d.name === "Exa research")?.ok ? "live" : "bundled"} · ` +
      `${sim?.householdCount ?? 0} households · ${sim?.evaluated ?? 0} projects · best ${best?.id ?? "none"} held in ${best?.futures?.passed ?? 0}/${best?.futures?.run ?? 0}`,
  );
}

const slugs = process.argv.slice(2).length > 0 ? process.argv.slice(2) : DEFAULT_SLUGS;
for (const slug of slugs) await recache(slug);
```
